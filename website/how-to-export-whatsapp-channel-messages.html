How to export WhatsApp Channel messages

WhatsApp does not provide a standard bulk export for Channels. This guide explains how to create a local archive from a Channel that you are authorized to view in WhatsApp Web.

What you need

  • Google Chrome or another supported Chromium browser
  • WhatsApp Web with the target Channel open
  • The latest WA Channel Exporter release

Install the extension

  1. Download and unzip the release package.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the extracted folder.
  4. Open WhatsApp Web and open the Channel you want to archive.

Create the export

  1. Open the extension side panel.
  2. Confirm that the active page is the intended WhatsApp Channel.
  3. Choose the date range and export scope.
  4. Start the scan and wait for the archive to download.

The archive can include an offline HTML viewer, CSV, Markdown, JSONL, media folders, and a manifest describing what was captured.

Important completeness limits

The extension captures what WhatsApp Web makes available in the active browser session. Scroll to load older posts before scanning. Expired or unavailable media may not download; the manifest reports missing and failed items rather than claiming a complete history.
